# FlyRank AI's Polite Scraper

## Overview
This is a simple project that focuses on web scraping, but politely of course.

## Target Classification
The target of this scraping practice will be `https://books.toscrape.com/` as it is a very popular site to practice scraping. 

This project focuses on just the first 3 pages, and will be scraping the book's information (e.g. Title, Price (including tax), and stock).

These data specifically aren't anything sensitive, so they will be appropriate for this practice.
